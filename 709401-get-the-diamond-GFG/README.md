# [Get the Diamond](https://www.geeksforgeeks.org/problems/get-the-diamond/1)
## Easy
Given two integers n and k, a diamond is located at the nth step. A person can jump either&nbsp;1 step or k steps at a time. Find the minimum number of jumps required to reach the nth step.
Examples:
Input: n = 4, k = 3
Output: 2
Explanation: First jump of K = 3 steps and second of 1 step.
Input: n = 2, k = 5
Output: 2
Explanation: Two jumps of 1 step each.
Constraints:1 ≤ n ≤ 1091 ≤ k ≤ 109
