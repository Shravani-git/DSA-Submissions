# [Row Sum in a Matrix](https://www.geeksforgeeks.org/problems/row-sum-in-a-matrix/1?page=1&category=Arrays&difficulty=Basic,Easy&status=unsolved&sortBy=latest)
## Easy
Given a 2-D integer matrix mat[][] of size n*m. Return a list of integers where list[i]&nbsp;represents the sum of elements of the&nbsp;ith&nbsp;row of the matrix.Note: The sum of any row will remain within the range of an integerExamples:Input: mat = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]Output: [6, 15, 24]Explanation: Row 1 -&gt; 1+2+3=6, Row 2 -&gt; 4+5+6=15, Row 3 -&gt; 7+8+9=24 Input: mat = [[1, 2], [10, 2], [3, 3]]Output: [3, 12, 6]Explanation: Row 1 -&gt; 1+2=3, Row 2 -&gt; 10+2=12, Row 3 -&gt; 3+3=6 Constraints:1 &nbsp;&lt;= &nbsp;n, m &nbsp;&lt;= &nbsp;1000
