# [Buzz Number](https://www.geeksforgeeks.org/problems/buzz-number/1)
## Easy
A number n is said to be a Buzz Number if it ends with 7 OR is divisible by 7.&nbsp; The task is to check whether the given number is Buzz number or not.&nbsp;
Examples:
Input: n = 63Output: trueExplanation: 63 is divisible by 7, one of the condition is satisfied.
Input: n = 72Output: falseExplanation: 72 % 7 != 0, 72 is neither divisible by 7 nor it ends with 7 so it is not a Buzz Number.
