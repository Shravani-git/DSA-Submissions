# [Even Occurring Elements](https://www.geeksforgeeks.org/problems/even-occurring-elements4332/1)
## Easy
Given an array arr[] of integers, find and return the elements with even occurrences in the array. If no such element exists, return -1. Elements should be returned in order of occurrence.
Examples:
Input: arr[] = [9, 12, 23, 10, 12, 12, 15, 23, 14, 12, 15]Output: [12, 15, 23]Explanation: The numbers 12, 15, and 23 each appear an even number of times.
Input: arr[] = [23, 12, 56, 34, 32]Output: [-1]Explanation: Every number in the array occurs an odd number of times.
Constraints:1 ≤ arr.size() ≤ 1061 ≤ arr[i] ≤ 105
