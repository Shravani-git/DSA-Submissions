# [Sum of n Even Squares](https://www.geeksforgeeks.org/problems/power-of-pow-even-number5440/1)
## Easy
Given a single integer n, your task is to find the sum of the square of the first n even natural Numbers.&nbsp;Examples:Input: n = 2
Output: 20
Explanation: 22 + 42 = 20
Input: n = 3
Output: 56
Explanation: 22&nbsp;+ 42&nbsp;+ 62 = 56&nbsp;
